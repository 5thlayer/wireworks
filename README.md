# Wireworks

Electric poles for NeoForge, after Factorio's. A pole powers every machine inside its supply area, with no cable run to each machine and no face to connect. Poles join into a network by wires, each within a pole's wire reach, and a network shares its generators' output among the machines it reaches.

Pole tiers, their supply areas and wire reaches are data, so a pack sets its own numbers.

Wireworks is a 5thlayer Library, carved out of the [FactoryWorks](https://github.com/5thlayer/factoryworks) Pack. It uses [Groundworks](https://github.com/5thlayer/groundworks) for placement, its preview and Fast Replace.
