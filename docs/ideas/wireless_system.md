# Wireless system

We have recently splitted the energy transport system into distribution and transmission, with the rationale of short and long distance energy logistics. I want to add a third one, the wireless system with finite and infinite distance.

The wireless system is an end game mechanic which allows powering machines without placing energy poles. The finite one powers an entire dimension while the infinite one transfers power between dimensions.

The wireless system requires a specific amount of stored void energy to function and the infinite consumes a specific amount per tick.
